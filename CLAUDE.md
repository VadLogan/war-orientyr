# WAR·Орієнтир — «Щоденний дайджест війни» (Next.js)

Daily war digest (UA/EN), mid-migration from a single-file Artifact to Next.js via strangler pattern. See README.md (Ukrainian) for the phase plan.

## Commands
- `npm run dev` — localhost:3000
- `npm run validate` — parses all `public/` JSON, checks digest.json schema keys and that `issues/index.json` contains digest's date. Run after any data change.
- `npm run build` — no test suite; validate + build is the check.

## Architecture (Phase 1)
- `app/page.tsx` — static markup shell with element IDs (`#main`, `#mast`, `#datebar`, `#viewSeg`, …) that legacy JS fills. Don't rename IDs.
- `components/LegacyApp.tsx` — loads `/legacy/d3.min.js` then `/legacy/app.js` once (guard vs StrictMode double effect).
- `public/legacy/app.js` — original script 1:1 (IIFE, minified-style, long lines). Renders everything: digest tab (`renderDigest`), dashboard (`renderDash`: timeline, losses, attacks/prices, recruitment, land cost, strikes map, maps comparison, SBS). Fetches data via relative paths with `cache:'no-store'`.
- `public/legacy/d3.min.js` — generated by `postinstall` from npm d3@7.9.0; never edit.
- `app/globals.css` — styles copied unchanged from original index.html.

## Data (`public/`)
- Updated daily: `digest.json`, `issues/<YYYY-MM-DD>.json`, `issues/index.json`, `strikes.json`; sometimes `prices.json`, `recruit.json`, `maps/maps.json`.
- Static: `landcost.json`, `maps/strikes-base.json`, `maps/targets.json`.
- Artifact is still the primary publisher; repo copy is synced manually, then validate + commit → Vercel deploys.

## Tools
- `tools/maps/extract.js` — browser-console snippet to pull map polygons from DeepState / ISW (ArcGIS) / DIVGEN; delta+DP-encoded rings, FNV hash.
- `tools/maps/build.py` — shapely/pyproj; decodes the `*.txt` extracts and builds `maps/maps.json`.

## Conventions
- UI strings live in `UI.uk` / `UI.en` in app.js. Content is Ukrainian-first.
- Deploy: Vercel (`@vercel/analytics`, `@vercel/speed-insights` in layout).
- Knowledge graph: `graphify-out/` (`.graphifyignore` excludes d3/data JSON). Run `graphify update .` after code changes.
